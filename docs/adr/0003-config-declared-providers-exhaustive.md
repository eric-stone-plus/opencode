# Config-declared providers and models are exhaustive

The seat must work on a censored network, so ModelsDev reads only its disk cache or bundled snapshot and never fetches implicitly (explicit refresh only: `opencode models --refresh`). A non-empty provider `models` block is exhaustive, and env keys, auth.json, plugin providers, and autoload loaders only supply credentials for providers declared in the config; `getSmallModel` never infers a model. This is a deliberate deviation from upstream's registry-merge behavior — do not "fix" it back.

**V2 (2026-10-12).** The V2 mechanisms: registry restriction lives in `ModelsDev.restrict` (`packages/schema/src/models-dev.ts`) and is applied by `normalize()` in `packages/core/src/models-dev.ts` to all four sources (file, KV, bundled snapshot, fetch); implicit fetch is off by default (`ModelsDev.Options.fetch`; `OPENCODE_ENABLE_MODELS_FETCH=1` turns it on, no new cached-CLI subcommand); and the declared-only rule is enforced by the internal plugin `fork.declared-providers` (`packages/core/src/plugin/fork/declared-providers.ts`), which drops providers a config never declares. `getSmallModel` still never infers.

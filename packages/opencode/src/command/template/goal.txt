The user issued the /goal command, which sets a persistent goal for this session.

Goal argument: $ARGUMENTS

Interpret the argument as follows:

1. Non-empty argument other than "clear": this text is now the session goal. It has been persisted and will be re-stated to you automatically on every turn, including after compaction. Acknowledge the goal in one short sentence, then continue working toward it.
2. Argument is "clear" (case-insensitive): the session goal has been removed. Confirm in one short sentence.
3. Empty argument: nothing was changed. State the current session goal in one short sentence (it appears in the system reminder when set), or say that no goal is set.
